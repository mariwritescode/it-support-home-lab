# Jira Service Management

## Overview

Jira Service Management was used to simulate a Help Desk ticketing environment for the IT Support Home Lab. Each incident was documented using a standard support workflow, including investigation, root cause analysis, resolution, verification, and ticket closure.

## Documented Incidents

### RPS-1 / HD-001
**User Unable to Access Accounting Share**

- Investigated user permissions
- Identified an NTFS permission issue
- Restored access to the Accounting share

### RPS-2 / HD-002
**Accounting Network Drive Missing**

- Investigated a missing mapped network drive
- Restored the network drive mapping
- Verified access to shared resources

### RPS-3 / HD-003
**Workstation Unable to Resolve Domain Resources**

- Investigated DNS configuration
- Corrected DNS settings
- Verified successful domain name resolution
