# Knowledge Base

## Overview

This section contains knowledge base (KB) articles created to support common Help Desk procedures and troubleshooting tasks within the Rocky's Pet Supply IT environment. Each article documents a repeatable solution that complements the Help Desk incidents in this project and provides a reference for future troubleshooting.

## Available Articles

### KB-001: Restoring Access to a Shared Folder
Documents the process for verifying user group membership, reviewing NTFS permissions, and restoring access to departmental file shares.

### KB-002: Mapping a Network Drive
Provides step-by-step instructions for mapping a network drive to a shared folder and verifying successful connectivity.

### KB-003: DNS Troubleshooting for Domain Resources
Documents DNS troubleshooting techniques, including verifying DNS settings, flushing the DNS cache, and validating name resolution using `nslookup`.
